# Modulo 1: JavaScript

## Obiettivi del Modulo

Questo modulo copre le fondamenta di JavaScript, dal livello base fino alla programmazione asincrona e alle API. L'approccio è pratico e progressivo, con esercizi che combinano concetti informatici puri e applicazioni interdisciplinari.

## Struttura del Modulo

### 📚 Sezione 1.1: Fondamenti (5 esercizi)
- Variabili e tipi di dati
- Operatori e espressioni
- Template literals e stringhe
- Type coercion e conversioni
- Console e debugging

### 🔀 Sezione 1.2: Strutture di Controllo (5 esercizi)
- Condizionali (if/else, switch)
- Operatore ternario
- Cicli (for, while, do-while)

### 📊 Sezione 1.3: Array e Metodi (6 esercizi)
- Array base e operazioni CRUD
- Iterazione e metodi array
- Spread e destructuring
- Metodi funzionali (map, filter, reduce)
- **PROGETTO**: Sistema Gestione Biblioteca

### ⚡ Sezione 1.4: Funzioni (6 esercizi)
- Function declaration ed expression
- Arrow functions
- Parametri, rest e spread
- Callback e Higher-Order Functions
- Closures e scope
- **PROGETTO**: Calcolatore Fisico Avanzato

### 🎯 Sezione 1.5: Oggetti (4 esercizi)
- Oggetti base e metodi
- Destructuring e spread
- Object methods avanzati
- **PROGETTO**: Database Eventi Storici

### ⏱️ Sezione 1.6: Asincrono e API (4 esercizi)
- Promises
- Async/Await
- Fetch API
- **PROGETTO FINALE**: Ricerca Normative

## Distribuzione UDA

- **14 Esercizi UDA**: Collegamenti con Fisica, Italiano, Storia, TLC, Diritto
- **16 Esercizi Puri**: Focus su concetti informatici
- **4 Progetti**: Applicazioni complete e integrate

## Prerequisiti

- Nessun prerequisito di programmazione
- Conoscenza base del computer
- Browser moderno con console sviluppatore

## Strumenti Necessari

- Editor di codice (VS Code consigliato)
- Browser moderno (Chrome/Firefox)
- Node.js (per alcuni esercizi avanzati)

## Come Usare Questo Modulo

1. Segui l'ordine degli esercizi (sono progressivi)
2. Leggi il README di ogni esercizio
3. Prova a risolvere l'esercizio autonomamente
4. Consulta la soluzione solo dopo aver tentato
5. Completa le sfide extra per approfondire

## Tempo Stimato

- **Tempo totale**: 60-80 ore
- **Per sezione**: 10-15 ore
- **Per esercizio**: 1-3 ore
- **Per progetto**: 4-6 ore
