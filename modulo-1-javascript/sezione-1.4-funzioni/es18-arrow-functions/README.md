# ES18 - Arrow Functions

## 📘 Tipo: PURO

## 🎯 Obiettivi
- Sintassi arrow functions
- Implicit return
- Comprend this context

## 📚 Teoria
```javascript
// Sintassi completa
const somma = (a, b) => {
  return a + b;
};

// Implicit return
const somma2 = (a, b) => a + b;

// Un solo parametro
const doppio = n => n * 2;

// No parametri
const saluta = () => "Ciao!";
```
