# Modulo 2: TypeScript

## Obiettivi del Modulo

Questo modulo introduce TypeScript e il sistema di tipi statici. Costruendo sulle competenze JavaScript del Modulo 1, imparerai a scrivere codice più robusto, manutenibile e type-safe.

## Struttura del Modulo

### 🔧 Sezione 2.1: Fondamenti TypeScript (5 esercizi)
- Setup e configurazione TypeScript
- Tipi primitivi e annotazioni
- Union, intersection e literal types
- Array e tuple tipizzate
- Enumerazioni (Enums)

### 🏗️ Sezione 2.2: Interfacce e Oggetti (5 esercizi)
- Interfacce base
- Interfaces vs Type aliases
- Function types
- Index signatures e mapped types
- **PROGETTO**: Sistema Particelle Fisiche

### 🎨 Sezione 2.3: Generics e Progetti (5 esercizi)
- Generics base
- Generic classes e interfaces
- Utility types (Partial, Required, Pick, Omit, Record)
- **PROGETTO**: Analizzatore Testi Letterari
- **PROGETTO FINALE**: Simulatore Circuiti

## Distribuzione UDA

- **8 Esercizi UDA**: Collegamenti con Fisica, Italiano, Storia, TLC, Diritto
- **7 Esercizi Puri**: Focus su TypeScript e type system
- **3 Progetti**: Applicazioni completamente tipizzate

## Prerequisiti

- **Completamento Modulo 1** (JavaScript)
- Familiarità con oggetti e funzioni
- Comprensione di programmazione asincrona (consigliata)

## Strumenti Necessari

- Node.js e npm
- TypeScript (installato via npm)
- Editor con supporto TS (VS Code consigliato)
- Configurazione tsconfig.json

## Setup Iniziale

```bash
# Installare TypeScript globalmente
npm install -g typescript

# Verificare installazione
tsc --version

# Creare tsconfig.json
tsc --init
```

## Come Usare Questo Modulo

1. Configura TypeScript seguendo ES31
2. Segui l'ordine progressivo degli esercizi
3. Compila sempre il codice (`tsc`) prima di eseguirlo
4. Presta attenzione agli errori del compilatore
5. Usa l'editor per sfruttare l'autocompletamento

## Vantaggi di TypeScript

- ✅ Type safety e prevenzione errori
- ✅ Autocompletamento intelligente
- ✅ Refactoring sicuro
- ✅ Documentazione self-describing
- ✅ Migliore manutenibilità del codice
