# Modulo 3: React con Vite

## Obiettivi del Modulo

Questo modulo introduce React, la libreria JavaScript per costruire interfacce utente moderne. Imparerai a creare componenti, gestire stato, lavorare con hooks e costruire Single Page Applications complete.

## Struttura del Modulo

### 🚀 Sezione 3.1: Setup e Componenti (5 esercizi)
- Setup Vite + React + TypeScript
- JSX e rendering
- Props e tipizzazione
- Composition e children
- Styling in React

### 🎮 Sezione 3.2: State e Interattività (5 esercizi)
- useState Hook
- Eventi e handlers
- State con oggetti e array
- Lifting state up
- Forms controllati

### ⚡ Sezione 3.3: Effects e Side Effects (3 esercizi)
- useEffect base
- Data fetching
- Cleanup e ottimizzazione

### 🎯 Sezione 3.4: Hooks Avanzati (4 esercizi)
- useContext
- useReducer
- Custom Hooks
- useMemo e useCallback

### 🧭 Sezione 3.5: Routing (3 esercizi)
- React Router setup
- Dynamic routes e params
- Layout e protected routes

### 🏆 Sezione 3.6: PROGETTI COMPLETI (5 esercizi)

- **ES67**: Archivio Letterario con API
- **ES68**: Task Manager Avanzato

## Setup Iniziale

```bash
# Creare nuovo progetto con Vite
npm create vite@latest my-react-app -- --template react-ts

# Entrare nella cartella
cd my-react-app

# Installare dipendenze
npm install

# Avviare dev server
npm run dev
```
